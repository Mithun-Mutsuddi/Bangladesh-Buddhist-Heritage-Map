# বাংলা অডিও গল্প — নিজের/শিক্ষকের কণ্ঠে রেকর্ড করার কিট

এই বিভাগের ৬টি বাংলা গল্প এখন **কৃত্রিম (AI) কণ্ঠে** পড়া। চাইলে নিজের বা কোনো শিক্ষকের কণ্ঠে
নতুন করে রেকর্ড করে সেই কণ্ঠ বসানো যায় — কার্ড থেকে “কৃত্রিম কণ্ঠ” লেবেলও তখন নিজে থেকেই সরে যাবে।

## ১. কী লাগবে

- একটা ফোন (ভয়েস রেকর্ডার), বা কম্পিউটারের মাইক। স্টুডিও লাগবে না।
- শান্ত ঘর — ফ্যানের শব্দ, রাস্তার আওয়াজ যতটা পারা যায় এড়িয়ে।
- পড়ার স্ক্রিপ্ট: **`assets/kids/audio/bn/recording-scripts-bn.pdf`** (৬ পাতা, বড় অক্ষরে — প্রিন্ট করে পড়া যায়)।

## ২. রেকর্ড করার নিয়ম

1. শুরুতে **২ সেকেন্ড নীরব** থাকুন, তারপর গল্প শুরু করুন।
2. ধীরে, স্পষ্ট করে পড়ুন — বাচ্চাদের শোনানোর জন্য।
3. শেষে আবার **২ সেকেন্ড নীরব** থাকুন।
4. ফাইলের নাম স্লাগ অনুযায়ী রাখুন (নিচে দেখুন), ফরম্যাট `mp3` (বা `wav`/`m4a`/`ogg`)।
5. প্রতিটি গল্প ১ মিনিটের মতো — একবারে না পারলে টুকরো করে রেকর্ড করে জোড়া দিলেও চলবে।

| ফাইলের নাম | গল্প | সময় (AI সংস্করণ) |
|---|---|---|
| `moon-rabbit.mp3` | শশক জাতক — চাঁদের খরগোশ | ০০:৫৮ |
| `white-elephant.mp3` | শ্বেত হস্তী জাতক | ০০:৫৪ |
| `angulimala.mp3` | বুদ্ধ ও অঙ্গুলিমাল | ০১:১৩ |
| `sujata.mp3` | সুজাতার মধুপায়স | ০০:৫৭ |
| `monkey-crocodile.mp3` | বানর ও কুমির | ০০:৫৯ |
| `banyan-deer.mp3` | বটহরিণ জাতক — ন্যাগ্রোধমৃগ | ০০:৫৮ |

## ৩. বসানোর কমান্ড

```bash
cd repo
python3 tools/install_bn_audio.py --list                 # কোন ফাইল দরকার দেখুন
python3 tools/install_bn_audio.py --dir ~/recordings --narrator "কণ্ঠশিল্পীর নাম"
python3 tools/build_kids_media.py                        # তালিকা নতুন করে তৈরি
node --test tests/                                       # টেস্ট
```

- নতুন রেকর্ডিং MP3 (৬৪ kbps, মনো) বানিয়ে বসানো হয়; **পুরোনো AI ফাইল মোছে না** —
  `assets/kids/audio/bn/ai-backup/` এ সরিয়ে রাখা হয়।
- `data/kids-audio-bn.json` হালনাগাদ হয়: `voice: human`, কণ্ঠশিল্পীর নাম, নতুন দৈর্ঘ্য।
- কার্ডে তখন লেখা হয় “কণ্ঠ: <নাম>” — “কৃত্রিম কণ্ঠ” লেবেল আর থাকবে না।

## ৪. ফিরিয়ে আনতে

```bash
python3 tools/install_bn_audio.py --revert
python3 tools/build_kids_media.py
```

## ৫. নিয়ম মনে রাখুন

- কণ্ঠশিল্পীর **সম্মতি** ছাড়া রেকর্ডিং প্রকাশ করা যাবে না (প্রকাশের নিয়ম: সম্মতি > লাইসেন্স)।
- কার্ডে কৃতিত্বে কণ্ঠশিল্পীর নাম রাখুন — স্ক্রিপ্ট স্বেচ্ছাসেবীদের ক্ষেত্রেও।
- অনুমোদন-কনসোল (`review.html`) থেকে পরে যেকোনো সময় লেখা/ছবি বদলানো যাবে।
