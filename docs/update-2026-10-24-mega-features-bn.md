# ২০২৬-১০-২৪ — মেগা ফিচার হালনাগাদ (Mega Features)

মালিকের চাওয়া ১১টি খণ্ডের প্রায় প্রতিটি ফিচার হয় **নতুন যোগ** করা হয়েছে, নয় **যেটা ছিল সেটা আরও বড়/ভালো** করা হয়েছে।
মূল নীতি আগের মতোই: **স্ট্যাটিক GitHub Pages-এ কোনো API key ছাড়াই চলবে**, ডেটা `data/*.json`-এ,
আর যেখানে আসল যাচাইকৃত তথ্য নেই সেখানে **বানানো কোনো নম্বর/তারিখ/দলিল দেখানো হবে না** — খালি ঘর + নির্দেশনা থাকবে।

## আপডেট করা বিদ্যমান পাতা

- **হোম (`index.html`)** — `#mega-hub` কার্ড-হাব + স্বয়ংক্রিয় পরবর্তী উৎসব মিনি-কার্ড (`heritage-plus.js`)।
  প্রতি স্থান-কার্ডে Street View / Earth / Timelapse / Lens শর্টকাট।
- **ক্যালেন্ডার (`calendar.html`)** — `#festivals-auto`: পঞ্জিকা-ইঞ্জিন দিয়ে **প্রতি বছর নিজে হবে**
  বুদ্ধ পূর্ণিমা, প্রবারণা, কঠিন চীবর দান, মাঘী, আষাঢ়ী, মধু পূর্ণিমা প্রভৃতি ৮ উৎসবের সম্ভাব্য তারিখ ও কাউন্টডাউন
  (জ্যোতির্বৈজ্ঞানিক পূর্ণিমা ±১ দিন ঘেঁসে স্পষ্ট দাবিত্যাগসহ; সরকারি ছুটির তালিকাই চূড়ান্ত)।
- **শিশু (`children.html`)** — `#games-plus`: XP/লেভেল/৮ ব্যাজ, ট্রেজার হান্ট, কুইজ কোয়েস্ট, স্ক্র্যাচ-অফ ডিগ,
  টাইম-ট্রাভেল আগে-পরে স্লাইডার, ছাপানো যায় এমন DIY পেপার-ক্র্যাফট (স্তূপ/বিহার নেট) ও ওয়ার্কশিট —
  Atlas পাসপোর্ট স্ট্যাম্পের সঙ্গে যুক্ত।
- **Atlas (`atlas.html`)** — Mega টুল লিংক-স্ট্রিপ।
- **সংঘমিত্র (`sanghamitra.js`)** — নতুন ১৫+ বিষয়ের স্থানীয় উত্তর (৩৬০°/GIS, বাজেট, Scholar, লিপি-সিল, চর্যাপদ,
  ৩১ ভূমি, মূর্তিতত্ত্ব, হরিকেল মুদ্রা, পরিব্রাজক, নিরাপদ দান, সার্টিফিকেট, বিশ্ব-তুলনা, জাদুঘর/আইনি, কমিউনিটি, কাগজে ঐতিহ্য);
  অনলাইন AI এবার `config.js`-এর `sanghamitraApiUrl` থেকেও পড়ে।
- **সার্ভার (`server/sanghamitra_api.py` v2.0.0)** — `AI_PROVIDER=openai|gemini`; Gemini-র জন্য
  `GEMINI_API_KEY` (বা `GOOGLE_API_KEY`), মডেল ডিফল্ট `gemini-2.0-flash`। চাবি **সার্ভারেই** থাকে।
- **ন্যাভিগেশন (`data/site-structure.json` v2)** — নতুন পাতাগুলো বিষয়-মেনুতে সাজানো (ঐতিহ্য ৭ · ভ্রমণ ১০ · লাইব্রেরি ৫ · যোগাযোগ ৮)।
- **PWA** — `manifest.webmanifest` + `sw.js` (`charyabhumi-v20261024-mega2`) + `pwa.js`:
  হোম-স্ক্রিনে যোগ, দুর্বল ইন্টারনেটে দ্রুত, একবার দেখা পাতা অফলাইনেও।

## নতুন ডেটা ফাইল (যা বদলালেই পাতা নিজে আপডেট হয়)

- `data/heritage-knowledge.json` — লিপি, সিল, চর্যাপদ, ৩১ ভূমি, মুদ্রা, পরিব্রাজক (§৪-৬)
- `data/travel-plus.json` — হাব-দূরত্ব, বাজেট হার, ৫টি রুট, nearby, accessibility (§৩)
- `data/research-plus.json` — পরিভাষা অভিধান, গ্রন্থপঞ্জি, বিশ্ব-তুলনা, জাদুঘর, আইনি কাঠামো (§২ §৭ §১১)
- `data/support-config.json` — দান (খালি + `verified:false`), সতর্কতা, ডেমো শপ, স্পনসর (বন্ধ) (§১০)
- `data/festivals-auto.json` — ৮ উৎসবের চান্দ্র-নিয়ম (§৮)
- `data/games-plus.json` — লেভেল, ব্যাজ, হান্ট/কুইজ/ডিগ/ওয়ার্কশিট (§৮)

## যা করা হয়নি / হাতে যাচাই লাগবে (ইচ্ছে করেই ফাঁকা)

1. **দানের নম্বর** — বিকাশ/নগদ/রকেট/ব্যাংক নম্বর বানানো হয়নি। প্রতিষ্ঠানের লিখিত অনুমতি পেলে
   `data/support-config.json`-এ `verified:true` দিয়ে নম্বর বসালেই শুধু দেখাবে।
2. **গেজেট/দাগ নম্বর, মুদ্রার ওজন, জাদুঘরের accession নম্বর** — সরকারি/জাদুঘর উৎস ছাড়া বসানো হয়নি;
   ফরম ও জায়গা তৈরি আছে।
3. **আসল 360° ট্যুর / DEM মান / YouTube ভিডিও আইডি** — ফেক আইডি নয়; অফিসিয়াল লিংক/এম্বেড ব্যবহার হয়েছে।
4. **Google/Firebase/AdSense/Analytics কী** — `config.js`-এ সব খালি প্লেসহোল্ডার। নিজের কী বসালে তবেই সেগুলো সক্রিয় হবে।
   Sanghamitra অনলাইন AI-এর জন্য সার্ভারে `GEMINI_API_KEY` বা `OPENAI_API_KEY` লাগবে (ব্রাউজারে চাবি নয়)।
5. **হোটেল/হাসপাতালের তালিকা সংরক্ষণ** — ভুল তথ্যের ঝুঁকিতে নয়; লাইভ Maps সার্চ লিংক দেওয়া হয়েছে।
6. **কমিউনিটি পোস্ট** — সার্ভার ছাড়া শুধু এই ব্রাউজরে খসড়া + কপি করে শেয়ার।
