Privacy & settings

No analytics, no location uploads, no public profile in this tracker.

Your explorer profile

Private by default

Visits and preferences are saved in this browser. Journals and media use IndexedDB. Clearing browser storage removes them. A shared device is not a private vault.

Share cards contain only the display name and progress. Your journal, companions and precise route are never included.

Back up your memories

Export a JSON backup including visits, routes, journals and media. Keep this file private: it can contain precise location history and photos.

Start fresh
