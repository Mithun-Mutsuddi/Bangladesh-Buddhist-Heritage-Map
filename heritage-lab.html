⚡ পারফরম্যান্স

Leaflet ম্যাপ lazy-লোড, ছবিতে loading="lazy", Service Worker ক্যাশে (HTML network-first), স্থানীয় ফন্ট। যাচাই: Chrome Lighthouse-এ Performance ≥ ৯০ লক্ষ্য রাখুন; বড় ছবি যোগ করলে WebP ও প্রস্থ-সীমা ব্যবহার করুন। Flutter চাইলে এই JSON ডেটা-স্তর সরাসরি ব্যবহারযোগ্য; Material-ধাঁচের UI-এর জন্য বিদ্যমান রঙ-টোকেন (CSS variables) নিন।

🔒 সিকিউরিটি

API সিক্রেট শুধু সার্ভারে; Firestore ব্যবহারে firestore.rules; হোস্টিংয়ে (Vercel/Cloudflare/GitHub Pages) HTTPS বাধ্যতামূলক, Referrer-Policy/X-Content-Type-Options হেডার চালু করুন। বিস্তারিত: আপডেট গাইড।
